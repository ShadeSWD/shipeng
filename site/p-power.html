Разбор 1. Индикаторная и эффективная мощность

Паспортная мощность двигателя — это результат стендовых испытаний, но на судне её приходится подтверждать по индикаторной диаграмме, снятой в рейсе. Задача показывает всю цепочку: от площади диаграммы к среднему индикаторному давлению, от него к индикаторной мощности, а от неё через механический КПД к эффективной мощности на выходном фланце.

Коротко

  • Среднее индикаторное давление — высота равновеликого прямоугольника: \(p_i = \dfrac{F}{l}\,m\), где \(F\) — площадь диаграммы, \(l\) — её длина, \(m\) — масштаб давления.
  • Мощность: \(N_i = \dfrac{p_i V_h z n}{\tau}\), где \(\tau = 1\) для двухтактного и \(\tau = 2\) для четырёхтактного двигателя.
  • Механический КПД связывает индикаторную и эффективную мощность: \(N_e = \eta_{\text{м}} N_i\), у судовых дизелей \(\eta_{\text{м}} = 0{,}85\ldots0{,}93\).
  • Для прототипа: \(p_i = 2{,}03\) МПа, \(N_i = 8410\) кВт, \(N_e = 7730\) кВт — расхождение с паспортными 7800 кВт менее 1 %.
  • Контрольные величины: литровая мощность 4,0 кВт/л и средняя скорость поршня 8,3 м/с — обе типичны для современного малооборотного дизеля.

Дано

Главный двигатель судна-прототипа — малооборотный двухтактный дизель с газотурбинным наддувом:

  • число цилиндров \(z = 6\);
  • диаметр цилиндра \(D_ц = 460\) мм, ход поршня \(S = 1932\) мм;
  • частота вращения \(n = 129\) об/мин;
  • паспортная эффективная мощность \(N_e^{\text{пасп}} = 7800\) кВт;
  • механический КПД \(\eta_{\text{м}} = 0{,}92\).

Индикаторная диаграмма, снятая с первого цилиндра: площадь \(F = 1580\) мм², длина диаграммы \(l = 78\) мм, масштаб пружины индикатора \(m = 0{,}1\) МПа/мм.

Найти: среднее индикаторное давление, индикаторную и эффективную мощность, среднее эффективное давление, механические потери, литровую мощность и среднюю скорость поршня.

Замкнутый контур диаграммы — работа газов за цикл. Площадь контура, растянутая на всю длину диаграммы, даёт высоту равновеликого прямоугольника: это и есть среднее индикаторное давление. Максимальное давление сгорания \(p_z\) на порядок выше \(p_i\) — не путайте эти величины.

Решение

Шаг 1. Рабочий объём цилиндра

Рабочий объём — объём, описываемый поршнем между мёртвыми точками:

$$V_h = \frac{\pi D_ц^{2}}{4}\,S$$
\(V_h = \pi D_ц^{2}S/4\) = 3,1416·0,46²·1,932/4 = 0,321 м³

Суммарный рабочий объём всех цилиндров \(V_h z = 0{,}321 \cdot 6 = 1{,}93\) м³ — почти два кубометра за один оборот вала.

Шаг 2. Среднее индикаторное давление по диаграмме

Площадь диаграммы, делённая на её длину, даёт среднюю ординату в миллиметрах; умножение на масштаб пружины переводит её в единицы давления:

$$p_i = \frac{F}{l}\,m$$
\(p_i = F m/l\) = 1580·0,1/78 = 2,03 МПа
Площадь диаграммы измеряют планиметром либо считают по оцифрованному контуру. Ошибка обвода в 3 % даёт ошибку мощности тоже 3 % — поэтому обводят не менее трёх раз и берут среднее.

Шаг 3. Индикаторная мощность

За один цикл газы совершают работу \(p_i V_h\) в каждом цилиндре. Число циклов в секунду равно \(n/\tau\), где \(\tau\) — коэффициент тактности: у двухтактного двигателя цикл завершается за один оборот (\(\tau = 1\)), у четырёхтактного — за два (\(\tau = 2\)). Отсюда

$$N_i = \frac{p_i V_h z n}{\tau}$$

Частота вращения в секундных единицах: \(n = 129/60 = 2{,}15\) с⁻¹.

\(N_i = p_i V_h z n/\tau\) = 2030·0,321·6·2,15/1 = 8 410 кВт

Здесь давление подставлено в килопаскалях, объём в кубометрах, частота в с⁻¹ — результат сразу получается в киловаттах.

Шаг 4. Эффективная мощность и механические потери

Часть индикаторной мощности расходуется на трение поршневых колец и подшипников, на привод навешенных насосов и продувочного агрегата. Эту долю учитывает механический КПД:

$$N_e = \eta_{\text{м}} N_i, \qquad N_{\text{м}} = N_i - N_e$$
\(N_e = \eta_{\text{м}} N_i\) = 0,92·8410 = 7 730 кВт
\(N_{\text{м}} = N_i - N_e\) = 8410 − 7730 = 680 кВт

Расхождение с паспортной мощностью 7800 кВт составляет

\(\delta = (N_e^{\text{пасп}} - N_e)/N_e^{\text{пасп}}\) = (7800 − 7730)/7800 = 0,9 %

что лежит внутри погрешности индицирования. двигатель развивает паспортную мощность

Шаг 5. Среднее эффективное давление

Ту же цепочку можно пройти в обратную сторону: по паспортной мощности найти среднее эффективное давление — условное давление, которое, действуя на поршень весь ход, дало бы эффективную мощность:

$$p_e = \frac{N_e \tau}{V_h z n} = \eta_{\text{м}} p_i$$
\(p_e = N_e \tau/(V_h z n)\) = 7800·1/(0,321·6·2,15) = 1,88 МПа
\(p_{\text{м}} = p_i - p_e\) = 2,03 − 1,88 = 0,15 МПа

Величина \(p_e = 1{,}88\) МПа характерна для современного малооборотного дизеля с высоким наддувом: у двигателей без наддува \(p_e\) не превышает 0,8 МПа, а рост до 1,8–2,1 МПа — прямая заслуга турбокомпрессора (см. главу 2).

Шаг 6. Контрольные показатели

Литровая (объёмная) мощность показывает, насколько напряжён рабочий процесс, а средняя скорость поршня — насколько напряжён механизм:

$$N_л = \frac{N_e}{V_h z}, \qquad c_m = \frac{S n}{30}$$
\(N_л = N_e/(V_h z)\) = 7800/(0,321·6) = 4 050 кВт/м³ = 4,05 кВт/л
\(c_m = S n/30\) = 1,932·129/30 = 8,31 м/с

Для малооборотных дизелей типичны \(c_m = 7\ldots9\) м/с: выше — растёт износ цилиндровых втулок, ниже — двигатель получается неоправданно громоздким.

Механические потери в поршневом двигателе невелики по сравнению с тепловыми: 7–8 % против почти половины теплоты топлива, уходящей с газами и водой. Где именно теряется теплота — в разборе 2.

Обсуждение результата

Все три оценки согласуются: индикаторная диаграмма даёт \(p_i = 2{,}03\) МПа, паспортная мощность — \(p_e = 1{,}88\) МПа, их отношение \(p_e/p_i = 0{,}926\) практически совпадает с принятым механическим КПД 0,92. Это и есть смысл индицирования: если бы отношение оказалось, например, 0,80, вывод был бы однозначным — механические потери выросли, надо искать заедание, перетяжку подшипников или неисправность навешенных механизмов.

Индицирование по цилиндрам решает и вторую задачу — выравнивание нагрузки. Если у одного цилиндра \(p_i\) на 8–10 % выше среднего, этот цилиндр перегружен: растёт температура выпускных газов, ускоряется износ. Регулировка выполняется изменением цикловой подачи топлива.

Вопросы для самопроверки

Почему у четырёхтактного двигателя при том же \(p_i\) и том же рабочем объёме мощность вдвое меньше?

Потому что рабочий цикл занимает два оборота коленчатого вала, то есть в секунду совершается вдвое меньше рабочих ходов: в формулу входит \(\tau = 2\). Именно поэтому двухтактные малооборотные дизели при равных габаритах развивают вдвое большую мощность, хотя часть хода теряется на продувку.

Чем среднее индикаторное давление отличается от максимального давления сгорания?

Среднее индикаторное давление — условная величина, высота равновеликого прямоугольника; максимальное давление \(p_z\) — реальный пик в конце сгорания, у современных МОД 14–18 МПа, то есть в 7–9 раз выше \(p_i\). Прочность деталей считают по \(p_z\), а мощность — по \(p_i\).

Как изменится \(p_e\), если отключить турбокомпрессор?

Без наддува в цилиндр поступит примерно втрое меньше воздуха по массе, значит, столько же можно будет сжечь топлива. Среднее эффективное давление упадёт до 0,6–0,8 МПа, а мощность — примерно втрое. Наддув и есть главный способ форсирования по мощности без роста габаритов.

Индикаторная диаграмма первого цилиндра дала \(p_i = 2{,}25\) МПа при среднем по двигателю 2,03 МПа. Что делать?

Цилиндр перегружен на 11 %. Нужно проверить температуру выпускных газов по этому цилиндру, состояние форсунки и топливного насоса и уменьшить цикловую подачу до выравнивания \(p_i\) по всем цилиндрам с разбросом не более ±2,5 %.
